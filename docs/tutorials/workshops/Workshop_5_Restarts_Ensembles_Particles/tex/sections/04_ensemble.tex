\section{Run a Monte Carlo ensemble}
Raven's ensemble modes run the model several times. With groundwater, Raven rebuilds the MODFLOW model and restarts MODFLOW
for each member. Each member writes its files into its own output folder.

\step{Set up the ensemble}
Go back to the first work folder:
\begin{shell}
$ cd $WS/work
\end{shell}
First undo the change of part~1 in \cmd{Creek.rvi}, so that the duration is three years again:
\diff{t5_undo.diff}
Then ask for five Monte Carlo members:
\diff{t5_ens.diff}
The ensemble file \cmd{Creek.rve} says what changes between the members. Here it is \cmd{PERC\_COEFF} of the subsoil, which
sets how fast the subsoil feeds the aquifer. It is drawn from a uniform distribution between 0.02 and 0.06~1/d. Create the
file \cmd{Creek.rve} with this content:
\showfile{finished/work/Creek.rve}
Or copy the file: \cmd{cp \$WS/model/finished/work/Creek.rve .}

\step{Run the ensemble}
\term{t5_run_ens.txt}
\term{t5_ls_ens.txt}
\see \cmd{Exiting Gracefully: Successful Simulation}, after about \V{t5:enssec}~seconds for \V{t5:nens} members. Each
folder \cmd{ens\_N} holds the outputs of one member, with its own \cmd{mf6}. The groundwater files and \cmd{mf6/}
directly in \cmd{out\_ens} come from the set-up before the first member and hold no results (headers only); use
\cmd{ens\_N}.
The script \cmd{plot\_ensemble.py} draws the members, with the continuous run of Step~3 for comparison:
\term{t5_plot_ensemble.txt}
\fig{t5_ensemble.png}{\cmd{ensemble.png}: the \V{t5:nens} members: the head at OW\_SLOPE and the recharge that reaches MODFLOW. The members' mean
recharge ranges from \V{t5:ensrmin} to \V{t5:ensrmax}~m\textsuperscript{3}/d, and the final head at OW\_SLOPE from
\V{t5:enshmin} to \V{t5:enshmax}~m.}
\why Raven's DDS and EnKF modes rebuild the groundwater model for each member in the same way. The next step removes
the two lines \cmd{:EnsembleMode} and \cmd{:RandomSeed} again. Raven reads the ensemble file only in ensemble mode, so
\cmd{Creek.rve} can stay.
