\begin{goal}
\textbf{What you do.} With the model of Tutorial Creek you split a run into two parts and continue the second part from the
file \cmd{solution.rvc}; the result equals the continuous run exactly. You run a Monte Carlo ensemble in which each member
rebuilds the groundwater model. And you save MODFLOW's flows to track particles backwards from the pumping well with
\cmd{make\_prt.py}.

\textbf{What you need.} A Linux computer (x86\_64) with a terminal, or Windows with WSL. Python~3 with numpy, pandas,
matplotlib and FloPy (Step~\ref{st:python}). A text editor, for example \cmd{nano}. Workshop~2 is helpful but not needed.

\textbf{Time.} About 30 minutes.
\end{goal}
