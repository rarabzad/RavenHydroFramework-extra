\section{Run the model with the default coupling}

\step{Copy the start model and run it}
The start model is the finished model of Workshop~2. Copy it into a work folder and run it as it is, into its own output
folder. You will compare all later runs with this one.
\begin{shell}
$ cp -r $WS/model/start $WS/work
$ cd $WS/work
\end{shell}
\term{t3_run_conceptual.txt}
\see \msg{Exiting Gracefully: Successful Simulation}. The run takes about \V{t3:secconceptual}~seconds.
