\section{Set up}

\step{Unpack the workshop}\label{st:unpack}
Copy \cmd{Workshop\_6\_Calibration\_With\_Ostrich.zip} into your home folder (on WSL, your Windows files are under
\cmd{/mnt/c/}). Unpack it, go into the new folder and set two variables: \cmd{WS} is the workshop folder and \cmd{RAVEN}
is the Raven program.
\begin{shell}
$ cd ~
$ unzip -q Workshop_6_Calibration_With_Ostrich.zip
$ cd Workshop_6_Calibration_With_Ostrich
$ export WS=$PWD
$ export RAVEN=$WS/bin/Raven
$ ls
\end{shell}
\see \cmd{README.txt}, this PDF and the folders \cmd{bin} (Raven and the MODFLOW~6 library), \cmd{model} (the calibration
folder at the start and at the end) and \cmd{tex}.
\begin{trouble}
\begin{itemize}
\item \cmd{unzip: command not found}: install it with \cmd{sudo apt install unzip}.
\item \cmd{Permission denied} when you run Raven later: type \cmd{chmod +x \$WS/bin/Raven}.
\item A message with \cmd{version \textasciigrave GLIBC\_2.34\textquotesingle{} not found} (for example after \cmd{cannot load MODFLOW 6
  library}): your Linux is too old. The programs need glibc 2.34 or newer (Ubuntu 22.04 or newer, Debian 12 or newer); \cmd{ldd
  --version} shows yours. On Windows, install a newer Ubuntu in WSL with \cmd{wsl --install -d Ubuntu-24.04}.
\end{itemize}
\end{trouble}
\begin{note}[Every new terminal]
\cmd{export} is valid only in the terminal where you typed it. OSTRICH starts Raven through the variable \cmd{RAVEN}, so
it must be set in the terminal where OSTRICH runs. In a new terminal, go to the workshop folder and type the \cmd{export}
lines again (also the \cmd{OSTRICH} line of Step~\ref{st:ostrich}).
\end{note}
